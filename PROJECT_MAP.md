## 7. Tests — `tests/`, 35 files, 10,141 lines

**1,071 tests.** In a bare shell: 1,070 pass, 1 skips by design.

```powershell
.\.venv\Scripts\python.exe -m pytest

# the one skip is the real-PostgreSQL schema check; to run it too:
$env:DATABASE_URL="postgresql+psycopg://finverify:finverify_dev@localhost:5433/finverify"
.\.venv\Scripts\python.exe -m pytest tests\test_database.py
```

It skips rather than passes on purpose, so a green run on a machine without
PostgreSQL never reads as *the schema was verified*.

**Research-validity gates — these are not ordinary tests.** If one fails, it is
a finding, not a test to update:

- `tests/test_channels.py` — the program channel cannot see Channel A
- `tests/test_index_manifest.py` — a model/collection mismatch is refused
- `tests/test_fiscal_year_filter.py` — a prior-year question still retrieves
- `tests/test_query_formulation.py` — each RX-017 arm's transform actually
  fires, so a null result cannot come from a broken transform
- `tests/test_source_hygiene.py` — no fabricated results in the tree
- `tests/test_gold_review.py` — the reviewer has no default answer, and
  `precheck_gold.py` cannot write a validation status
